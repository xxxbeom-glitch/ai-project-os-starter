# 00 PROJECT BRIEF — LinkPocket

## 한 줄 정의
웹에서 발견한 링크를 저장하고, 나중에 빠르게 다시 찾을 수 있게 하는 개인용 북마크 웹앱.

## 문제
사용자는 좋은 글·도구·영상 링크를 여러 앱과 브라우저에 흩어 저장하고, 나중에 어디에 저장했는지 잊는다.

## 대상
- 20~40대 지식노동자
- 디자이너, 개발자, PM, 마케터
- 웹 리서치와 자료 저장이 잦은 사용자

## 핵심 가치
**저장은 5초 안에, 다시 찾기는 10초 안에.**

## MVP
- 이메일 로그인
- URL 저장
- 제목 자동 입력 또는 직접 수정
- 카테고리 지정
- 메모 작성
- 링크 목록
- 검색
- 수정 / 삭제

## MVP 제외
- 팀 협업
- AI 자동 요약
- 브라우저 확장 프로그램
- 모바일 네이티브 앱
- 추천 알고리즘
- 소셜 기능

## 성공 지표
- 가입 후 첫 링크 저장 완료율
- 주간 저장 사용자 비율
- 저장 후 7일 이내 재열람률
- 검색 성공률
- D7 재방문

## 방향성
초기 목표는 기능을 많이 만드는 것이 아니라 **저장 → 정리 → 재발견**의 핵심 루프가 실제로 유용한지 검증하는 것이다.

## Non-goal
LinkPocket은 처음부터 Notion, Readwise, Pocket 전체를 대체하지 않는다.
