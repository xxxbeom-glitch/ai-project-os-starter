# 01 PRODUCT POLICY — LinkPocket

## 목적
제품이 기능별로 즉흥적인 결정을 하지 않도록 사용자·데이터·콘텐츠·계정 정책의 기본선을 정한다.

## 계정
- MVP는 이메일 로그인만 지원한다.
- 한 사용자의 데이터는 다른 사용자에게 공개되지 않는다.
- 로그아웃 후 인증이 필요한 화면에 접근할 수 없다.

## 사용자 데이터
- 저장 링크, 카테고리, 메모는 사용자 소유 데이터다.
- 서버는 사용자별 ownership을 강제한다.
- 탈퇴 시 개인 데이터 삭제 절차를 제공한다.
- 운영 편의를 이유로 사용자의 private bookmark를 공개 데이터처럼 사용하지 않는다.

## 링크 콘텐츠
- LinkPocket은 링크의 원문 콘텐츠를 소유하지 않는다.
- MVP는 URL·제목·사용자 메모 중심으로 저장한다.
- 외부 페이지가 삭제되거나 접근 불가가 되어도 저장 기록 자체는 남길 수 있다.

## 삭제
- 사용자가 북마크를 삭제하면 사용자 화면에서는 즉시 제거한다.
- 실제 삭제/백업 정책은 구현 전 별도 Decision으로 확정한다.

## 안전과 오용
- 악성 URL 자동 판정 시스템은 MVP 범위가 아니다.
- 명백한 보안 위험이 확인되면 링크 열기 전에 경고하는 기능을 후속 검토한다.

## 변경 규칙
회원, 개인정보, 공개범위, 데이터 삭제 정책은 Development Agent가 임의 변경할 수 없다. 변경 시 Decision을 먼저 만든다.
